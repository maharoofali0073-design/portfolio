# Maharoof Ali — Portfolio

AI & Automation Engineer portfolio. Built with React, TypeScript, Tailwind CSS, Framer Motion and Lucide React (Vite).

Live: https://maharoofali0073-design.github.io/portfolio/

## Run locally

```bash
npm install
npm run dev      # development
npm run build    # production build into dist/
```

## Edit the content

All text lives in `src/data.ts` (name, tagline, about text, services, projects, workflow tiles, contact links).
The hero photo is `public/maharoof.webp`.

## Deploy

Every push to `main` builds the site and publishes it to GitHub Pages (`.github/workflows/deploy.yml`).
